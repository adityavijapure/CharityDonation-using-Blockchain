So according to given problem statement we worked on a website of charity trust management and tracking system. 
The website is build by using following tech:
frontend- React+Tailwind
Database- Firebase

The main purpouse of the website is to provide security and transperency in the transaction of funds in charity trusts. Its also helpful for tracking the proper utilization of the raised funds by charity trusts.
